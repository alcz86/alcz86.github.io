Lessons

Command cheat sheet
dbt run
Build every model, in dependency order.
dbt test
Run every data test against what is already built.
dbt build
Run and test together, model by model. Skips everything downstream of a failure.
dbt compile
Render the Jinja into plain SQL without running it.
dbt run -s stg_orders+
One model plus everything downstream of it.
dbt run --full-refresh
Rebuild incremental models from scratch.
dbt docs generate
Builds a docs site with this same lineage graph.

How this lab differs from real dbt: it runs SQLite in your browser, flattens schema.table to schema_table, and supports the Jinja you need here: ref, source, config, this, is_incremental(). No macros, seeds or snapshots. Your edits are saved in this browser; the warehouse resets on reload.
